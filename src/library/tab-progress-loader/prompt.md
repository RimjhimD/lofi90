Build a React + TypeScript + Tailwind "Tab Progress Loader": a progress loader for long jobs (exports, uploads, report generation) that keeps reporting in the browser tab itself. When the user switches to another tab, this tab's favicon becomes a filling progress ring and its title reads "42% · Exporting report", so they can work elsewhere and still see it finish. No extra libraries.

Props (typed): progress (0–100, or null when the length is unknown), status ("idle" | "running" | "done" | "error" | "cancelled"), label (default "Exporting report"), tabMode ("hidden-only" | "always" | "off", default "hidden-only"), notify (system notification when it ends while the tab is hidden), sound (short quiet chime when done, off by default), onCancel (shows Cancel while running), onRetry (shows Try again after an error), errorMessage, disabled (locks Cancel, e.g. near the end), variant ("bar" | "ring"), tabPreview (draws a small mock browser tab strip that mirrors the real tab), previewState ("idle" | "running" | "indeterminate" | "done" | "error" | "cancelled" | "disabled"), labels (every visible, announced and tab-title string, with {p}, {label}, {title} and {t} placeholders), accent (default "#C6FF3D"), doneColor, errorColor, size ("sm" | "md" | "lg") and className. Also export askTabNotifications() for asking permission from a click.

Behaviour:
- The favicon is drawn on a 64 px canvas and exported as a PNG data URL: a dark disc with a faint track and an accent arc for the percent; a rotating arc when progress is null (4 frames a second, and three still dots with reduced motion); a green disc with a white ✓ when done; a red disc with a white ! on error.
- Titles: "{p}% · {label}" while running, "Working · {label}" when the length is unknown, "✓ Ready · {page title}" when done, "Failed · {label}" on error.
- The first time it writes, it saves the page's own title and the href of every link rel="icon" (adding one if there is none). It only ever changes hrefs, and restores everything exactly. If several loaders exist, only the last writer restores.
- Writes are throttled to 4 a second and only happen when the whole percent, the icon or the colours change.
- "hidden-only" shows progress only while the tab is hidden (read through useSyncExternalStore on visibilitychange). Done and error stay in the tab until the user comes back, then the page's own title and icon return. If the job ends while the user is watching, the tab is left alone. "always" also shows progress while visible and holds ✓ for 4 seconds. On unmount everything is restored.
- Notifications: permission is only asked from a click (a small "Notify me when it's done" button, or askTabNotifications in your own handler). If granted and the tab is hidden when the job ends, it shows "Export ready"; clicking it focuses the tab. Denied or unsupported just says the tab icon still shows ✓.
- In the page: a card with the label, percent, a bar (or ring), a time-left line worked out from the measured rate over the last 10 seconds (updated twice a second), and Cancel or Try again. Unknown length shows a sliding segment. Screen readers hear the start, every 25%, and the outcome in a role="status" region; the bar is a role="progressbar" with aria-valuenow (left out when unknown).
- previewState draws one state with fixed sample values, renders no real buttons, and never touches the document title or favicon.

Look: calm control-room card — #121614 panel, 1px #3A433F border, rounded corners, lime accent fill, monospace percent, muted hint text, coral error text, small bordered buttons with a lime focus ring that stays visible on light and dark stages. The mock tab strip shows two neighbour tabs and this one in the middle with the same icon drawn as SVG, captioned "Your browser tab right now" or "when you switch away". Reduced motion: no sliding bar, no spinning, no width transitions.
