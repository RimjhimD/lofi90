Build a React + TypeScript + Tailwind "Live URL Slug Input": a page-title field that builds a clean web address underneath it as you type, checks whether that address is free, and offers free versions when it is taken. No extra libraries.

Props (typed): value / defaultValue ({ title, slug, locked, redirect? }; controlled or uncontrolled), onChange (gets { title, slug, locked, redirect, available: boolean | null }), prefix (default "mysite.com/blog/"), checkAvailability ((slug, signal: AbortSignal) => Promise<boolean>; throw to show the error state), debounceMs (default 400), suggest ((slug, { title, year }) => string[], to replace the built-in ideas), maxSuggestions (default 3), maxLength (default 60), removeStopWords (default false) and stopWords (list), published and originalSlug, names ({ title, slug, redirect } form field names; the slug goes in a hidden input), onStatusChange ((status, slug)), onPick ((slug)), labels (partial overrides for every visible and announced string, including the word that replaces "&"), accent (slug highlight colour, default "#C6FF3D"), size ("sm" | "md" | "lg"), disabled, previewState ("empty" | "typing" | "checking" | "available" | "taken" | "manual" | "published" | "error" | "disabled": draw one state with sample text, with spans instead of buttons and inputs, nothing running) and className.

Behaviour:
- The slug is built live from the title: lower-case; accents become plain letters (é→e via Unicode NFKD, plus ß→ss, æ→ae, œ→oe, ø→o, ł→l, þ→th and similar); "&" becomes the "and" label; apostrophes vanish (it's → its); every other symbol, emoji or space becomes a single dash; no double dashes and no dash at either end. With removeStopWords, small words like "the", "and", "of" are dropped (unless nothing would be left).
- Longer than maxLength: cut at the last dash before the limit, never in the middle of a word, with a quiet "Shortened to 60 characters at a word break" note.
- Under the field, a monospace address bar shows prefix in muted text and the slug highlighted with a faint accent wash and ring, then the status and a lock button.
- After debounceMs without changes, checkAvailability runs for the newest slug only. Each new slug aborts the previous check with its AbortController and late answers are ignored. Status: checking (small spinner), free (✓, accent text), taken (✕, error text), error (with a Retry button). The bar border follows the status.
- When taken: build ideas (slug + current year, a shorter version without small words or without the last word, slug-2, slug-3; or the suggest prop), clean and cap each one, check them all, and show only the free ones as pill buttons. Clicking one makes it the slug. If none are free, say so.
- Lock: while locked the slug follows the title. Pressing the lock unlocks it and focuses an inline slug box that cleans up as you type (a trailing dash is allowed until you leave the box). Once unlocked, title changes never overwrite the slug. "Re-sync with title" (or the lock again) puts it back in step. Picking a suggestion also unlocks.
- Published: when published and the slug differs from originalSlug, a calm amber box says "Old links will break", names the old address, and offers an "Add a redirect from the old address" checkbox (on by default) whose value is in onChange. A published page starts unlocked so the title never moves a live address.
- onChange fires on every edit and again when an availability answer arrives, so `available` stays current.
- Screen readers hear "mysite.com/blog/x is free." / "is taken. 3 free suggestions below." / the error in a polite role="status" region, only once a check settles.

Look: control-room style using --k-* CSS variables with dark fallbacks (panel #121614, field #181D1B, lines #3A433F, text #E9EDE8, muted #8A938D), so it reads on light and dark stages. Rounded field with a clear hover and focus border, a recessed monospace address bar, small rounded-full suggestion pills that light up on hover, a 28px square lock button showing a closed or open padlock, visible focus rings in var(--k-acc-text), disabled dims and blocks everything, spinner and caret only animate when motion is allowed. Works at 375px: the prefix and slug truncate before anything wraps.
