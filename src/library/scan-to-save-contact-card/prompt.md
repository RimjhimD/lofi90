Build a React + TypeScript + Tailwind "Scan-to-Save Contact Card": a team or profile card with a live QR code. Pointing a phone camera at the screen offers to save the person straight into the phone's contacts, and a "Save contact" button downloads the same details as a .vcf file, which on a phone opens the add-contact screen. No extra libraries: write the QR encoder and the vCard builder yourself in small helper files.

Props (typed): contact (firstName, lastName, middleName, prefix, suffix, org, title, phones [{ number, type: "cell" | "work" | "home" }], emails [{ address, type: "work" | "home" }], website, address { street, city, region, postalCode, country }, note, photoUrl), qrSize (px, default 128), showQr ("always" | "desktop-only", default "desktop-only"), device ("auto" | "desktop" | "mobile", default "auto"), layout ("horizontal" | "vertical"), ecLevel ("L" | "M" | "Q", default "M"), accent (default "#C6FF3D"), qrColor (default "#0B0D0C"), size ("sm" | "md" | "lg"), showAvatar, fileName, labels (partial overrides for every visible and announced string: save, saved, savedMark, savedHint with {name}, qrHint, mobileHint, zoom, zoomTitle, zoomHint, close, copy, copied, copyEmail and copyPhone with {value}, copiedEmail, copiedPhone, copyFailed, loading, tooLong, and the cell / work / home / email tags), onSave(vcard, contact), onCopy(kind, value), onZoom(open), disabled, loading, previewState ("default" | "qr-zoomed" | "saved" | "mobile" | "vertical" | "minimal" | "disabled" | "loading") and className.

Behaviour:
- QR encoder (qr.ts): byte mode with UTF-8 text, error correction L/M/Q/H, the smallest version from 1 to 40 that fits, Reed–Solomon codewords over GF(256) with polynomial 0x11D, block splitting and interleaving, finder, timing and alignment patterns, all eight masks scored with the four standard penalty rules, BCH format and version information. Drawn as one SVG path on white with a 4-module quiet zone and shape-rendering="crispEdges". Text that is too long shows a short message instead of a code.
- vCard 3.0 builder (vcard.ts): N and FN, ORG, TITLE, TEL with CELL / WORK / HOME types, EMAIL, URL, ADR, NOTE and an optional PHOTO URL. Escapes backslash, newline, comma and semicolon; CRLF line ends; lines folded at 75 bytes without ever cutting a UTF-8 character in half.
- The QR code leaves the photo link out to stay small (phone cameras don't fetch it); the downloaded file includes it.
- Save contact builds a Blob of type text/vcard, downloads it as "first-last.vcf" in the click itself (so phones allow it), shows "Saved ✓" for a few seconds, announces it and calls onSave with the exact file text.
- Clicking the QR code opens it large in a native modal dialog (focus moves in, Esc, Close or a click outside closes it, focus returns). A hint under the code says "Point your phone camera here".
- On a touch-only phone screen, "desktop-only" hides the QR code because you can't scan your own screen, and the button goes full width with a hint. Detected with matchMedia in useSyncExternalStore, so server and first render agree.
- Small Copy buttons next to each phone number and email write to the clipboard and say so; a failure says so too.
- Avatar shows the photo, or initials on an accent gradient if there is no photo or it fails to load.
- loading draws a skeleton and blocks the button; disabled turns off saving, copying and zoom and dims the code. previewState draws any state still, with the whole card inert.

Look: control-room style. Panel #121614 with a 1px #3A433F border and soft shadow, rounded corners, name in bold, title and company muted, details in a tidy two-column list. Save button in the accent colour with text colour picked for contrast, lifting on hover and sinking on press; the saved state turns dark with accent text. The QR always sits on white for reliable scanning and gets an accent ring on hover. All colours come from --k-* CSS variables with dark fallbacks so it reads on light and dark stages, focus rings use var(--k-acc-text), and hover zoom, the dialog's entrance and the skeleton pulse are off with reduced motion.
