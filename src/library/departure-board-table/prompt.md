Build a React + TypeScript + Tailwind "Departure Board Table": a live-updating data table drawn as an airport split-flap board. When a value changes, its letters flip through the flap drum to the new value and the cell stays marked for a few seconds, so nobody misses a status change. While the pointer or keyboard focus is on the board, updates wait so rows never jump under the reader, and screen readers get a short summary of each batch instead of every letter. No extra libraries.

Props (typed, generic over the row type T): rows (T[]), getRowId ((row) => string), columns (array of { key, header, value: (row) => string, width? in characters, align? "left" | "right", tone? (row) => "ok" | "warn" | "bad" | "neutral", announce? (default true; turn off for noisy columns like a countdown), sortable? }), caption (board title and table caption), rowLabel? (how a row is named in announcements, default first column header + value), holdOnHover (default true), flipMs (time per letter step, default 60), markMs (how long a changed cell stays marked, default 4000), loading, error (true or a message string), onRetry, updatedAt (Date or ms), stale (force the stale look), staleAfterMs (default 60000), sortBy ({ key, dir } starting sort), onSortChange, onApply ({ changed, added, removed } after each update lands), onHoldChange ((held, waiting) => void), labels (partial overrides for every visible and announced string: waiting(n), showNow, heldNotice, changed(row, column, value), added(row), removed(row), more(n), loading, empty, emptyHint, error, errorHint, retry, updated(ago), ago(ms), stale, sortHint), accent (letter colour of neutral cells and the changed marker, default "#FFB547"), toneColors, size ("sm" | "md" | "lg"), uppercase (default true), previewState ("live" | "flipping" | "held" | "loading" | "empty" | "error" | "stale" — render one state without running anything) and className.

Behaviour:
- Keep a snapshot of the rows on show. When new rows arrive, diff them against it by row id and column key: changed cells, added rows, removed rows. Only changed cells flip.
- Each character is its own tile. A tile walks the drum " ABC…Z0-9.,:-/#&'+·" from the old letter to the new one, at most 5 steps, one step every flipMs. Each step folds the top half down over the old letter and drops the bottom half with the new one (Web Animations, rotateX). Tiles in a cell start one after another, left to right. A newer value cancels the rest of the walk.
- Values are fitted to the column width: upper-cased, cut with "…" if too long, padded by alignment. The full value is in a visually hidden span, so a screen reader reads the real text, not the tiles.
- A changed cell gets an accent left bar and tint that fades over markMs, starting from the real age of the change.
- New rows flip in from blank. Removed rows stay in their old place, flip to blank, then leave (aria-hidden while they go).
- Hold: while the pointer is over the board or focus is inside it, incoming rows are not applied. A pill shows "3 updates waiting · Show now"; Show now applies them and keeps focus on the board; leaving applies them. Screen readers hear once that updates are waiting.
- Announcements: a polite role="status" region. Messages from updates are collected for about a second, then read as one line, at most three items plus "and N more changes" ("Order 1042 status changed to Ready").
- Sorting: header buttons cycle ascending, descending, off; aria-sort on the th; stable sort with numeric-aware compare. Held updates don't reorder anything.
- Loading: four rows of tiles spinning to random letters, aria-busy on the table. Error: the board flaps "SERVICE INTERRUPTED" with a hint and a Retry button in a role="alert". Empty: "NOTHING SCHEDULED". Stale (forced or older than staleAfterMs): the table dims and the footer shows "Last update 2 min ago" with a warning badge.
- Reduced motion (read with useSyncExternalStore): no flips, values change in place, the changed marker still shows.
- Responsive: the table scrolls sideways inside a focusable region, with the first column sticky as row headers.

Look: the board is always dark hardware (#0F1110 frame, tiles in two-tone charcoal with a black hinge line), monospace letters in the accent amber, ok/warn/bad cells in green, yellow and coral that all clear 4.5:1 on the tiles. Painted header labels in a small bold sans, caption in wide-tracked capitals. The hold pill uses the accent with text colour picked for contrast. Focus rings inside the board use the accent so they show on the dark board on light and dark pages. Hover brightens header buttons, press dims them.

Look props: accent, size ("sm" | "md" | "lg") and flipMs, plus holdOnHover on/off, for the live controls panel.
