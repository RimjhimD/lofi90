Build a React + TypeScript + Tailwind "Permission Primer" modal. It shows before the browser's own camera / microphone / location / notification popup, because once a user clicks Block the browser never asks again and the feature is lost for good. No extra libraries.

Props (typed interface): permission ("camera" | "microphone" | "geolocation" | "notifications"), open and onOpenChange (controlled), reason (why the app needs it, in plain words), optional title, benefits (up to three), onGranted, onDenied, request (optional override of the real browser call, returning "granted" or "denied"), autoCloseMs and previewState (render one state inline for docs and tests).

Behaviour:
- Use the native <dialog> element with showModal(), so focus trapping, Esc and the inert background come for free. Esc and a backdrop click call onOpenChange(false). Label it with aria-labelledby and aria-describedby.
- When it opens, check what the browser already knows first, with navigator.permissions.query (Notification.permission for notifications). Already granted means call onGranted and close without showing anything. Already denied means go straight to the Blocked state.
- Check support: needs a secure context plus mediaDevices.getUserMedia, navigator.geolocation or Notification. Otherwise show a "not available here" state with "Continue without".
- States: checking, prompt (explain screen with icon, reason and a benefits checklist, plus "Not now" and a primary "Allow camera"), asking (button shows a spinner and a bouncing badge points to the top-left corner where the browser popup appears), granted (green check, onGranted, auto-closes after autoCloseMs), denied (browser-specific numbered steps to re-enable, for Chrome, Edge, Safari and Firefox, plus "Try again", which re-queries and shakes the card if it's still blocked), unsupported.
- The default request uses the real APIs: getUserMedia (and stop the tracks straight away), getCurrentPosition, Notification.requestPermission.

Look: switchboard style. 2px #1A1A17 ink lines, hard offset shadow, white card on bone #F2EEE3, square-cornered buttons (signal red #D7263D with white text for the main action, bottle green #0E3B2E for done), a red notice tag pointing at the browser prompt, and a simple outlined SVG icon per permission. Open animation with the Web Animations API. Respect prefers-reduced-motion, AA contrast, and an aria-live status line that announces each state.
