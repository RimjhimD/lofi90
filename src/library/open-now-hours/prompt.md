Build a React + TypeScript + Tailwind "Open-Now Hours" section: a business-hours block for local business sites that answers "can I go now?" at a glance, such as "Open now · closes in 45 min", "Closing soon · last bookings 7:45 PM" or "Closed · opens tomorrow at 9:00 AM". All time-zone math uses Intl.DateTimeFormat with a timeZone option. No extra libraries.

Props (typed): hours (WeeklyHours: mon…sun → "closed", "24h" or a list of ["HH:MM","HH:MM"] ranges; two ranges make a lunch break; a close at or before the open runs past midnight, e.g. ["18:00","01:00"]; missing days are closed), timeZone (the business's IANA zone), exceptions (array of { date: "YYYY-MM-DD", hours, label? } for holidays and special hours; each replaces that date's normal hours), now (Date | number, fixed time for tests and demos), soonMinutes (default 30), lastBookingMinutes (default 15), showVisitorTime (default true), visitorTimeZone (detected from the browser when left out), ctaWhenOpen and ctaWhenClosed (ReactNode slots, e.g. Call now / Book online), name (heading), locale (times and day names come from Intl in this locale), labels (partial overrides for every visible and announced string, with {in}, {time}, {when}, {last}, {place}, {local}, {date}, {label} placeholders), onStatusChange(status), lookaheadDays (default 14), defaultExpanded, previewState ("open" | "closing-soon" | "overnight" | "open-24h" | "closed-opens-later-today" | "closed-opens-tomorrow" | "closed-opens-later" | "holiday" | "loading"), accent, openColor, soonColor, closedColor, size ("sm" | "md" | "lg") and className. Also export a pure getOpenStatus({ hours, timeZone, now, exceptions, soonMinutes }) function.

Behaviour:
- Read the business's wall clock with formatToParts. Build the open ranges for yesterday through a week ahead (exceptions replace the weekday's hours), and merge touching ranges, so an overnight range and a following 24-hour day join into one open span.
- Open: find the span holding now; closing time is its end. Closed: the next span's start. Turn that wall time back into a real instant (offset from formatToParts, checked twice) so "closes in" stays right across daylight-saving changes.
- States: closing soon when minutes left ≤ soonMinutes (amber, shows the last booking time); open 24 hours when the span covers all of today; open late when it crosses midnight; open otherwise (green). Closed is a holiday when today has an exception, otherwise it opens later today, tomorrow or on a named day (red).
- When the visitor's zone has a different offset, add "8:00 PM in Dhaka = 2:00 PM your time" for the next change, with the weekday if the date differs.
- Show today as a bar from midnight to midnight: open ranges tinted, the current one stronger, a marker at now. Below it the next upcoming exception ("Coming up · Fri, 31 Oct: Closed for Puja holiday"), then a button that expands a table of the next seven days starting today, with today highlighted (aria-current="date") and exception labels under their dates.
- The clock comes from useSyncExternalStore: it ticks on each minute boundary, stops while the tab is hidden and catches up when it's visible again. The server snapshot is null, so the server renders a neutral loading skeleton and the static week, and "now" is only worked out in the browser. No hydration mismatch.
- A role="status" line announces the state and its target time ("Closing soon. Closes today at 8:00 PM."), so it only speaks when the state changes, not every minute. onStatusChange fires at the same moments.
- previewState draws one state still with no clock and no listeners: it searches the coming week of the given hours in 15-minute steps for a real moment in that state (falling back to a built-in sample week), and renders no buttons or slots.
- An unknown time zone falls back to UTC instead of throwing.

Look: calm control-room card, var(--k-panel) background, 1px var(--k-line) border, rounded corners, a coloured status dot with a soft ring next to a bold status heading, detail text in var(--k-text) and secondary lines in var(--k-mute). Status colours only tint the dot, the bar and the holiday pill, so text contrast never depends on them. The now marker is a thin var(--k-text) line with an accent cap; today's row in the table gets an accent bar. Focus rings use var(--k-acc-text), the toggle has hover and pressed states, the bar marker and chevron only animate without reduced motion. Look props: accent, size and soonMinutes for the live controls panel.
